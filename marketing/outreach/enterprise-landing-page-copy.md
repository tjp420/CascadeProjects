#### The Risk You Can't See

AI coding assistants (Copilot, Cursor, Claude Code) generate 20-40% of new code in enterprises that adopt them. That code carries risks traditional scanners don't detect:

- **Hallucinated dependencies** — npm packages that don't exist → supply chain attack vectors
- **Placeholder credentials** — `apiKey: 'your-api-key-here'` committed to production → data breaches
- **License contamination** — copyleft code from AI training data → IP litigation
- **Error suppression** — generic `catch{}` blocks that mask production failures → extended outages

Each of these has a dollar impact. SimpleBeacon quantifies it.

#### The Risk Certificate

Every scan produces an **Executive Risk Certificate** — a signed PDF that includes:

- Overall compliance score (0-100) with letter grade
- 3x3 Risk Heatmap (severity x likelihood) for visual board reporting
- Finding-by-finding breakdown with statutory fine risk mapping
- Remediation roadmap with priority ordering
- SHA-256 integrity hash for tamper-evidence

#### Continuous Compliance

Don't just scan once. SimpleBeacon integrates with your **Azure DevOps CI/CD pipeline** to generate compliance evidence on every pull request:

```yaml
# Azure DevOps Pipeline Template (included with Enterprise)
- script: |
    simplebeacon scan \
      --path "$(SCAN_PATH)" \
      --gate \
      --fail-on high \
      --format json \
      --output "$(Build.ArtifactStagingDirectory)/simplebeacon-report.json" \
      --api-key "$(SIMPLEBEACON_API_KEY)"
```

Your audit evidence is always current. Always signed. Always ready.
