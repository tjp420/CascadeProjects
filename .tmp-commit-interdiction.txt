feat(security): real-time key interdiction engine with auto-block on anomaly threshold

Add an in-memory API key block list inside authorize.cjs that
automatically interdicts tokens when cross-tenant violation rates
cross configured thresholds. Interdicted keys receive HTTP 423
Locked on subsequent requests until the TTL expires or an admin
manually releases the lock.

authorize.cjs (updated):
- interdictedKeys Map: In-memory store of blocked keys with
  { reason, blockedAt, expiresAt, source } metadata.
- interdictKey(apiKey, reason, ttlMs, source): Adds a key to the
  block list with configurable TTL (default: 15 min). Enforces
  memory cap (10,000 entries) with FIFO eviction.
- releaseKey(apiKey): Removes a key from the block list immediately.
- checkInterdiction(apiKey): Checks if a key is blocked, with lazy
  TTL eviction on access (no background timer needed).
- getInterdictedKeys(): Returns masked list of blocked keys + stats.
  API keys are truncated to first 4 + … + last 4 chars.
- enforceKeyInterdiction(): Express middleware that checks the
  request's API key (x-api-key header, query.apiKey, or req.user.id)
  against the block list. Returns 423 Locked with expiresAt
  timestamp. Does NOT leak internal reason/blockedAt/source.
- Auto-interdiction: recordViolation() now calls interdictKey()
  automatically when org partition violations cross the configured
  threshold (default: 5 violations). The caller's userId is blocked
  for the configured TTL.
- clearInterdictedKeys(): Admin/test reset function.
- _resetInterdictionStats(): Test helper.
- recordViolation: Now exported for test access.
- All functions configurable via security-monitor-settings-store:
  interdictionDefaultTtlMs, interdictionMaxKeys,
  interdictionAutoTriggerEnabled.

audit-routes.cjs (updated):
- GET /api/audit/interdiction/status: Returns block list + stats
  (admin-only, authorize('admin:all')).
- POST /api/audit/interdiction/block: Manually block a key with
  { apiKey, reason?, ttlMs? } (admin-only).
- POST /api/audit/interdiction/release: Release a blocked key with
  { apiKey } (admin-only, returns wasBlocked flag).
