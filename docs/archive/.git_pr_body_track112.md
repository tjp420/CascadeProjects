**Summary**
Adds a runnable operational prototype for Track 112 attestation and concurrency telemetry.

**What this change includes**
- **PoRep Verifier:** sha256 binary Merkle proof verifier with 4 KiB leaves, 32-challenge verification and deterministic path checks.
- **Worker Pool & Ingest:** non-blocking worker-pool, bounded ingest queue, backpressure at 768/1024.
- **Telemetry:** increments for successes and failures (`hsm_track112_proofs_verified_total` / `hsm_track112_proofs_failed_total`) wired into task completion paths.
- **Bench & Tests:** micro-benchmark for concurrency and unit tests verifying Merkle proofs and ingest backpressure.

**Verification**
- Unit tests: all Track112 suites pass locally.
- Bench: 500 jobs @ concurrency=4 → throughput ~35,714 ops/s, p95 ≈ 12 ms.

**Follow-ups**
- Replace in-memory leaves with chunked file I/O and streaming multipart uploads.
- Harden PoRep to support signature/auth chaining and per-tenant rate limits.
- Add CI benchmark gating (opt-in).
