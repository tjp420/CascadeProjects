# Privacy Policy

## Data Collection

SimpleBeacon does not collect personal data from users during normal operation. All scanning and analysis runs locally in the user's browser or via their own CLI installation.

## Local Processing

- Source code and file metadata are analyzed entirely on the user's machine.
- No code, file contents, or scan results are transmitted to external servers unless the user explicitly exports a report.

## External Services

When users choose to connect to external services (e.g., GitHub API, Stripe billing), only the minimum necessary data is exchanged:

- Authentication tokens are stored in browser `localStorage` or encrypted storage.
- No source code is transmitted during authentication or billing operations.

## Cookies and Local Storage

The application uses `localStorage` for:

- License token persistence
- User preferences (theme, panel states)
- Cached scan results (optional, user-controlled)

No tracking cookies or third-party analytics are used.

## Contact

For privacy-related questions, contact the project maintainers.
