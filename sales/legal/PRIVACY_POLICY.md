# Privacy Policy

**Last Updated:** June 9, 2026

## 1. Overview

AI Slop Cop is designed with privacy as a core principle. This policy explains how we handle your data.

## 2. Data Collection

### 2.1 Local Processing
- All source code scanning happens locally on your machine
- Your source code never leaves your computer
- No code is sent to SimpleBeacon servers

### 2.2 Minimal Data Collection
We may collect:
- License token for validation
- Anonymous usage statistics (scan counts, rule usage)
- Error reports (no code content)
- Operating system and VSCode version

### 2.3 No Personal Code Storage
- We do not store your source code
- We do not analyze your code beyond the local scan
- Scan results are stored locally on your machine

## 3. License Token

### 3.1 Purpose
License tokens are used solely to:
- Validate your subscription tier
- Enable Pro/Enterprise features
- Prevent unauthorized use

### 3.2 Token Storage
- Tokens are stored locally in your VSCode settings
- Tokens are encrypted at rest
- Tokens are never shared with third parties

## 4. Usage Data

### 4.1 Anonymous Statistics
We may collect anonymous data to improve the product:
- Number of scans performed
- Rules triggered
- Extension version
- Platform information

### 4.2 No Personal Information
Usage data does not include:
- File names
- Code content
- Project structure
- Personal identifiers

## 5. Data Security

### 5.1 Encryption
- License tokens are encrypted
- Data transmission uses HTTPS
- Local data is protected by OS security

### 5.2 Data Retention
- Scan results: Stored locally only
- Usage statistics: Aggregated and anonymized
- License tokens: Stored until subscription ends

## 6. Third-Party Services

We do not share your data with third parties for:
- Advertising
- Selling
- Data mining

## 7. Your Rights

You have the right to:
- Access your license token
- Delete your account and data
- Opt out of usage statistics
- Request data deletion

## 8. Children's Privacy

AI Slop Cop is not intended for children under 13. We do not knowingly collect data from children.

## 9. International Data Transfers

Since all scanning is local, no international data transfers occur for source code. License validation may involve minimal data transfer to our servers.

## 10. Policy Changes

We will notify users of significant changes to this policy via:
- Email (if provided)
- In-extension notification
- Website update

## 11. Contact

For privacy-related questions: privacy@simplebeacon.com
