# SimpleBeacon CLI Installation Roadmap

## 1. Global Installation (System-Wide Shell)
```bash
npm install -g simplebeacon-cli
```
*Note: Run in an elevated shell if corporate permission structures require administrator privileges.*

## 2. Project Local Installation (Dev Dependency)
```bash
npm install --save-dev simplebeacon-cli
npx simplebeacon-cli --help
```

## 3. Ephemeral Single Run (No Local Footprint)
```bash
npx simplebeacon-cli@latest scan --path .
```
