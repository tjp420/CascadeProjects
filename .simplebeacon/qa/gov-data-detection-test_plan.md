## Scope — phased delivery

### Phase 1 — Classification spillage (G-01, G-02) — **Priority P0**

**Goal:** Block release on controlled-unclassified information markers in production paths.

**New files:**
- `packages/simplebeacon-cli/src/rules/classification-spillage-patterns.js`
- `packages/simplebeacon-cli/src/rules/classification-spillage-catalog.json`
- `packages/simplebeacon-cli/tests/classification-spillage-patterns.test.js`
- `packages/simplebeacon-cli/tests/fixtures/classification-spillage/` (toxic + clean samples)

**Proposed rule IDs:**

| ID | Pattern class | Severity | Example |
|----|---------------|----------|---------|
| `SB-GOV-001` | CUI banner | critical | `CUI//`, `CONTROLLED UNCLASSIFIED INFORMATION` |
| `SB-GOV-002` | FOUO / legacy marking | critical | `FOUO`, `FOR OFFICIAL USE ONLY` |
| `SB-GOV-003` | NOFORN / REL TO | critical | `NOFORN`, `REL TO USA` |
| `SB-GOV-004` | Classification keyword block | high | `SECRET//`, `TOP SECRET//` in non-doc context |
| `SB-GOV-005` | Export control context | medium | `ITAR-controlled`, `EAR99` in prod source (tuned allowlist for docs) |

**Integration:**
- Register in `scan.js` as `classification-spillage-patterns`
- Add to `.simplebeacon/config.json` under `rules` with `enabled: true` for `gov` profile
- Gate: `critical` findings block by default

**False-positive guards:**
- Skip `*.md` in `docs/` unless `productionPaths` match
- Allowlist test fixtures under `simplebeacon-toxic-fixtures/classification/`
- Ignore lines with `simplebeacon-ignore classification-spillage`

### Phase 2 — AI-origin provenance (G-03) — **Priority P1**

**Goal:** Flag code likely AI-generated that lacks review markers before merge.

**New files:**
- `packages/simplebeacon-cli/src/rules/ai-provenance-patterns.js`
- `packages/simplebeacon-cli/src/lib/git-hunk-metadata.js` (optional: parse `git diff` / blame for last author)
- `packages/simplebeacon-cli/tests/ai-provenance-patterns.test.js`

**Detection layers (static first, git optional):**

| ID | Signal | Severity |
|----|--------|----------|
| `SB-AI-PROV-001` | `@generated` / `@ai-generated` without `@reviewed` nearby | high |
| `SB-AI-PROV-002` | Copilot ghost comment patterns (`// Generated by GitHub Copilot`) | medium |
| `SB-AI-PROV-003` | Large stub functions (empty body / `not implemented`) in `productionPaths` | high — overlap with slop, dedupe |
| `SB-AI-PROV-004` | File never touched by human email domain in git log (opt-in `--with-git-provenance`) | medium |

**Config:**
```json
"ai-provenance-patterns": {
  "enabled": true,
  "requireReviewMarker": true,
  "reviewMarkers": ["@human-reviewed", "simplebeacon-reviewed", "REVIEWED-BY:"],
  "withGitProvenance": false
}
```

**Note:** Git layer off by default (air-gap may lack git); static markers first.

### Phase 3 — Cross-domain handoff export (G-04) — **Priority P1**

**Goal:** `simplebeacon export handoff` produces lower-side-safe bundle from scan report.

**Extend:**
- `packages/simplebeacon-cli/src/lib/report-sanitizer.js` → add `sanitizeHandoffExport(report, options)`
- New CLI subcommand or flag: `simplebeacon scan --handoff-export handoff.json`

**Strip/redact:**
- Absolute paths → `[REDACTED_PATH]`
- Windows usernames in paths (`C:\Users\...`)
- Internal hostnames / IP literals (except `127.0.0.1`)
- Email addresses in findings
- CUI strings (reuse Phase 1 patterns)
- Code snippets → hash + line count only (optional `--include-redacted-snippets`)

**Tests:**
- `packages/simplebeacon-cli/tests/handoff-export-sanitize.test.js`

---

### Phase 4 — Offline trust artifacts (G-05, G-06, G-08) — **Priority P2**

**G-05 — Local signing:**
- `packages/simplebeacon-cli/src/lib/local-certify.js`
- Sign report hash with `SIMPLEBEACON_SIGNING_KEY` or `--signing-key-file`
- Output `.sbcert` compatible with existing verify flow but **local public key**
- `--certify` remains online; new `--certify-local` for air-gap

**G-06 — Scan manifest:**
- Append to `report.json`:
  ```json
  "scanManifest": {
    "engineVersion": "...",
    "rulePackHash": "...",
    "findingsHash": "...",
    "repoFingerprint": "sha256(...)",
    "offlineMode": true,
    "networkViolations": []
  }
  ```

**G-08 — Audit log:**
- `simplebeacon audit-log append --report report.json` → `.simplebeacon/audit-chain.jsonl` (hash-chained entries)

## Config profile: `gov-local`

Add to `.simplebeacon/config-gov-local.json`:

```json
{
  "profile": "gov-local",
  "rules": {
    "credentials": { "enabled": true },
    "classification-spillage-patterns": { "enabled": true, "severity": "critical" },
    "llm-slop-patterns": { "enabled": true },
    "token-bleed-patterns": { "enabled": true },
    "owasp-llm-patterns": { "enabled": true },
    "agency-handoff-patterns": { "enabled": true },
    "pii-logging": { "enabled": true },
    "ai-provenance-patterns": { "enabled": true }
  },
  "gate": {
    "blockOn": ["critical"],
    "classificationSpillageBlocks": true
  }
}
```

CLI usage:
```bash
npx simplebeacon scan --config .simplebeacon/config-gov-local.json --offline --air-gapped --gate
```
