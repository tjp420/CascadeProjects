# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue
2. Email security@simplebeacon.ai with details
3. Include steps to reproduce and impact assessment
4. Allow up to 72 hours for initial response

We will acknowledge receipt, investigate, and provide updates on remediation timeline.
