# Article 50 Transparency Disclosure

## AI System Notice

This project includes an AI-powered code analysis assistant that helps developers review and improve code quality.

## What This System Does

- Analyzes source code for quality issues, security vulnerabilities, and best practices
- Suggests code improvements and fixes
- Generates reports on codebase health

## Human Involvement

**All code changes require human review and approval.** The AI assistant:
- Cannot modify code without explicit developer consent
- Cannot deploy or push code to repositories
- Cannot make autonomous decisions about code changes

## Transparency

- This system uses local AI models (Ollama) running on the developer's machine
- No code is sent to external AI services without explicit configuration
- All processing happens in the local development environment

## User Rights

As a developer using this tool, you have full control:
- Review all suggestions before applying them
- Reject any suggestion you disagree with
- Disable the AI assistant at any time
- Maintain full ownership of your codebase

## Contact

For questions about this AI system, refer to the project documentation or the risk assessment document.
