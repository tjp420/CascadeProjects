feat(security): master key rotation & migration dashboard panel

Add backend admin routes and frontend UI for managing cryptographic
key rotations, tracking background ledger migration metrics, and
forcing manual re-keying sweeps from the Security Admin dashboard.

audit-routes.cjs (updated):
- GET /api/audit/key/status: Returns live keyring status with
  truncated SHA-256 fingerprints (16 chars), rotation timestamp,
  grace window info, and hasPrevious/hasActive flags.
- POST /api/audit/key/rotate: Accepts { newKeyRaw, graceMs } and
  triggers keyRotationStore.rotateKey(). Validates key is present
  and >= 32 chars. All routes wrapped with authorize('admin:all').
- POST /api/audit/key/rekey-now: Forces an out-of-band re-keying
  sweep via auditLogger.runAutonomousReKeying(). Returns migration
  counts (migrated, skipped, failed, purged).
- GET /api/audit/key/rekey-stats: Returns background worker
  statistics (totalSweeps, totalMigrated, totalFailed, etc.).
- key-rotation-store lazy-loaded via getKeyRotationStore() to
  avoid circular dependency issues at module init time.

keyManagementService.js (new):
- fetchKeyStatus(): GET /api/audit/key/status
- triggerKeyRotation(): POST /api/audit/key/rotate
- forceReKeySweep(): POST /api/audit/key/rekey-now
- fetchReKeyStats(): GET /api/audit/key/rekey-stats
- generateRandomKey(): Web Crypto API 256-bit key generator
- formatGraceCountdown(): Human-readable grace window countdown

SecurityView.js (updated):
- renderKeyManagementSection(): Admin-only card with:
  - Active/previous key fingerprint display (truncated SHA-256)
  - Grace window countdown badge
  - Rotation form (password input + Generate + Rotate buttons)
  - Background re-keying stats grid (sweeps, migrated, skipped,
    failed, purged)
  - "Force Re-Key Sweep" button for manual migration trigger
- handleKeyRotation(): Posts to /key/rotate, clears input.value

- handleForceReKey(): Posts to /key/rekey-now, refreshes stats
- handleGenerateKey(): Fills input with Web Crypto random key
- loadKeyStatus(): Fetches status + stats, called on mount for
  admin users
- All event listeners wired in render() method
