Hey Product Hunt! 👋

I’m the maker behind SimpleBeacon Compliance Gate.

A few months ago, a friend’s B2B startup missed a massive $50k enterprise contract during legal procurement. The blocker? A junior engineer had accidentally pulled down a sub-dependency wrapped in an AGPL-3.0 license, legally threatening their core proprietary IP.

Most compliance frameworks cost $5k–$15k, require intrusive cloud access, and take weeks to configure. Developers hate them.

I built SimpleBeacon to fix this. It’s an elite, lightning-fast static code auditor built explicitly for modern engineering teams:

🔒 100% Local Sandbox: Your source code never leaves your local browser or terminal. No privacy risk.
📦 Deep-Dependency Resolution: Traces nested sub-dependencies to catch hidden viral copyleft licenses (GPL/AGPL).
🛑 CI/CD Pipeline Gate: A 5-minute GitHub Action that breaks the build the exact second a toxic module or cloud secret is introduced.
🛠️ Auto-Remediation: Automatically generates ready-to-paste markdown Pull Request descriptions to patch violations in minutes.

The core browser sandbox and CLI engine are completely free. If you want continuous protection for your master codebase, you can upgrade to our CI Action gate.
