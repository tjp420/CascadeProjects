## 1. AI System Overview

SimpleBeacon includes AI-powered analysis capabilities that scan source code for security, compliance, and quality patterns. The system uses heuristic pattern matching (regex) and static analysis to detect:

- AI SDK imports and integration patterns
- Hardcoded credential patterns
- Debug artifacts (console.log, debugger)
- License and governance markers
- TODO/FIXME technical debt markers
- Duplicate files and unused assets
