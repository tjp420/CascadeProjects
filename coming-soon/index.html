The 4 Failure Patterns That Kill AI-Shipped Code

Backed by Columbia DAPLab 2025 and CodeHalu (AAAI 2025). SimpleBeacon catches them locally — before merge, before prod, before the postmortem.

#1 — 37% of agent bugs

Phantom APIs

Agents hallucinate method calls on real libraries — fs.readFilePromise, JSON.tryParse, Promise.retry. 100+ patterns detected with the real API suggestion.

#2 — silent prod failures

Swallowed Exceptions

Empty catch blocks, except: pass, return nil without wrapping. The agent "fixed" the error but the failure surfaces in production at 3am.

#3 — broken builds

Hallucinated Imports

Imports that don't exist, wrong export names, packages the agent invented. Caught before the build, not after.

#4 — reviewable slop

LLM Slop

Markdown fences in code, TODO: implement, sample/mock production paths, fiction KPIs. Stripped before review, not during.

Gate Compliance in Your CI Pipeline

Copy-paste these configs to automatically fail pull requests on credential leaks, AI-slop debris, and compliance violations. No agent installation required.

.github/workflows/simplebeacon-gate.yml 
name: SimpleBeacon Compliance Gate

on: [pull_request]

jobs:
  compliance-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Install SimpleBeacon
        run: npm install -g simplebeacon
      - name: Run compliance gate scan
        env:
          SIMPLEBEACON_LICENSE_TOKEN: ${{ secrets.SIMPLEBEACON_LICENSE_TOKEN }}
        run: simplebeacon scan . --gate --format json --output=report.json
      - name: Upload compliance report
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: simplebeacon-report
          path: report.json
      - name: Fail PR on critical violations
        if: failure()
        run: echo "::error::Compliance gate failed. Check the report artifact for details."
.gitlab-ci.yml 
simplebeacon-gate:
  stage: test
  image: node:20
  before_script:
    - npm install -g simplebeacon
  script:
    - simplebeacon scan . --gate --format json --output=report.json
  artifacts:
    paths:
      - report.json
    expire_in: 30 days
  variables:
    SIMPLEBEACON_LICENSE_TOKEN: $CI_SIMPLEBEACON_LICENSE_TOKEN
  rules:
    - if: $CI_PIPELINE_SOURCE == "merge_request_event"

Set SIMPLEBEACON_LICENSE_TOKEN in your CI secrets. Gate fails on critical findings. Report artifact is available for auditors.
