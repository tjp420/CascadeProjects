Data Processing Agreement

Last updated: July 2026

Provider: SimpleBeacon (“Processor”)

Scope: All paid tiers (Pro, Compliance Suite, Enterprise Air-Gapped)

Legal basis: GDPR Article 28, UK GDPR Article 28, CCPA §1798.140

Status: Active Available for countersignature upon request

1. Roles and Responsibilities

You (the Client) are the Data Controller. You determine the purposes and means of processing your source code, scan results, and user data.

SimpleBeacon is NOT a Data Processor for your source code. SimpleBeacon does not receive, process, store, or transmit your proprietary source code, file contents, or repository data at any point during scanning operations. All scanning occurs locally on your infrastructure.

SimpleBeacon acts as a limited Data Processor only for the following non-source-code data categories:

  • Account metadata: email address, tier, license token (for authentication and billing)
  • Billing data: processed by Stripe (PCI-DSS Level 1 certified) — SimpleBeacon never stores card numbers
  • Anonymized scan statistics: issue counts, gate pass/fail status (only if team dashboard is enabled; never includes code snippets, file paths, or file contents)
  • Contact form submissions: name, email, message (processed by Formspree for routing)

2. Zero-Upload Warranty

SimpleBeacon warrants that:

  • The CLI scanner (simplebeacon scan) makes zero network requests during scanning unless the user explicitly passes --upload to generate a certificate.
  • The browser sandbox scanner executes entirely in the client browser's memory. No source code is transmitted to any server. The sandbox is wiped when the browser tab closes.
  • The VS Code extension shells out to the local CLI. No cloud API is invoked for scanning.
  • The Enterprise Air-Gapped deployment operates with zero internet connectivity after initial Docker image pull. License tokens are validated locally using HMAC-SHA256.

This warranty is enforceable as a Service Level Agreement. Any violation constitutes a material breach of contract.

3. Data Custody SLA

SimpleBeacon explicitly warrants that it never acts as a data custodian for client proprietary IP. Specifically:

  • SimpleBeacon does not store, cache, or retain client source code on any server, database, or log system.
  • SimpleBeacon does not have access to client repositories, CI/CD pipelines, or development environments.
  • Scan reports and certificates are generated client-side and stored on the client's local filesystem. SimpleBeacon has no copy.
  • The optional team dashboard receives only anonymized aggregate statistics (issue counts, pass/fail). No file names, code snippets, or repository paths are transmitted.

4. Sub-Processors

SimpleBeacon uses the following sub-processors for non-source-code data only:

  • Stripe, Inc. — Payment processing (PCI-DSS Level 1). Processes card data directly; SimpleBeacon receives only a payment token. Stripe Privacy Policy
  • Cloudflare, Inc. — CDN, DNS, DDoS protection, and web analytics. Processes IP addresses and request metadata. Cloudflare Privacy Policy
  • Formspree, Inc. — Contact form routing. Processes name, email, and message content. Formspree Privacy Policy
  • Google (Fonts) — Font delivery via Google Fonts CDN. Processes IP address for font request. Google Privacy Policy

Client will be notified at least 30 days in advance of any new sub-processor being added. Client may object to a new sub-processor by terminating their subscription.

5. Data Subject Rights

Since SimpleBeacon does not process client source code, data subject rights (access, rectification, erasure, portability) apply only to account metadata and anonymized scan statistics. Clients may exercise these rights by emailing admin@simplebeacon.ai. Requests are fulfilled within 30 days.

For source code and scan reports, data subject rights are exercised directly by the client on their local infrastructure — SimpleBeacon has no data to return or delete.

6. Breach Notification

In the event of a personal data breach affecting account metadata or billing data, SimpleBeacon will:

  • Notify the client within 72 hours of becoming aware of the breach (GDPR Article 33 compliant)
  • Provide a detailed description of the breach, likely consequences, and measures taken
  • Cooperate with the client's investigation and regulatory notifications

Since SimpleBeacon does not store source code, a source code data breach is not possible within SimpleBeacon's infrastructure.

7. Cross-Border Data Transfers

Account metadata is stored in the client's chosen region:

  • EU Frankfurt, Germany (AWS eu-central-1)
  • US Virginia, USA (AWS us-east-1)

No cross-border data transfer occurs without explicit client consent. Standard Contractual Clauses (SCCs) are available upon request for clients in the EEA or UK.

8. Security Measures

SimpleBeacon maintains the following technical and organizational security measures:

  • Encryption in transit: TLS 1.2+ for all network communication (HSTS enforced)
  • Encryption at rest: AES-256 for account metadata storage
  • Access control: Least-privilege IAM; no default access to production data
  • Audit logging: All authentication and billing events are logged with 90-day retention
  • Vulnerability scanning: Continuous dependency scanning via Dependabot and npm audit
  • Content Security Policy: Strict CSP headers enforced on all production pages
  • Incident response: Documented runbooks with 4-hour response SLA for critical incidents

9. Audit Rights

Clients may audit SimpleBeacon's compliance with this DPA by:

  • Requesting a SOC 2 Type II report (available annually)
  • Conducting network traffic audits as documented on our Security & Trust page
  • Reviewing the Technical Whitepaper for architecture details
  • Requesting a live demonstration of air-gapped scanning in their environment

On-site audits are available for Enterprise Air-Gapped clients with 30 days' notice.

10. Deletion on Termination

Upon subscription termination, SimpleBeacon will:

  • Revoke all license tokens immediately
  • Delete account metadata within 30 days (retained only where required by tax law)
  • Provide a written confirmation of deletion upon request
  • Client scan reports and certificates remain on the client's local filesystem — SimpleBeacon has no copy to delete

11. Governing Law

This DPA is governed by the laws of the jurisdiction specified in the client's master subscription agreement. For EU clients, the GDPR and relevant member-state implementations apply. For US clients, CCPA and relevant state laws apply.
