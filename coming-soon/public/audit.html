Run via CLI

Run from your repository root. Copy a command and paste it into your terminal.

npm install -g file:packages/simplebeacon-cli
Verify CLI
$ node packages/simplebeacon-cli/bin/simplebeacon.js scan --help Verify CLI is ready
$ node packages/simplebeacon-cli/bin/simplebeacon.js scan . --format json --output=report.json Standard gate scan
$ node packages/simplebeacon-cli/bin/simplebeacon.js scan . --gate --offline Gate-only (no network)
$ node packages/simplebeacon-cli/bin/simplebeacon.js scan . --complete --gate --format json --output=report.json Full coverage + gate
$ node packages/simplebeacon-cli/bin/simplebeacon.js scan . --complete --gate --format json --output=eu-ai-act-report.json EU AI Act assessment
