FAQ

Common questions about SimpleBeacon.

Does SimpleBeacon upload my source code?

No. All scanning happens locally in your IDE or browser sandbox. Your code never leaves your machine unless you explicitly choose to upload a report for certificate generation.

What is the difference between Free and Pro?

Free includes 24 real-time regex rules in the VS Code extension. Pro ($9/month) adds 14 batch analyzer engines, CLI scanning, CI/CD gate integration, and exportable reports.

Can I cancel my subscription?

Yes. You can cancel anytime from your account settings. You keep access until the end of your billing period. We also offer a 7-day money-back guarantee.

Do you offer refunds?

Pro tier has a 7-day no-questions-asked money-back guarantee. Enterprise refunds are handled per contract.

How do I install the VS Code extension?

Search "Simplebeacon" in the VS Code Extensions marketplace, or visit our listing directly. Current version: v3.0.438.

How do I update the VS Code extension?

VS Code auto-updates extensions by default. To manually update: open Extensions (Ctrl+Shift+X), find "AI Slop Cop", and click "Update". Or download the latest .vsix from the marketplace listing and install via code --install-extension simplebeacon-3.0.438.vsix.
