SimpleBeacon Auto-Fix (Preview)

This release introduces a conservative deterministic auto-fix framework for common issues detected by the SimpleBeacon scanner.

What it fixes automatically

  • insecureRandom: replaces Math.random() with a crypto-backed inline helper (Node.js projects)
  • debugArtifacts: removes debugger; and console.debug(...) calls
  • innerHtmlXss: converts safe innerHTML = '' assignments to textContent = ''

What it suggests (non-destructive)

  • sensitiveData: generates redaction diffs and environment-variable guidance; secrets are never removed automatically
  • hardcoded confidence and LLM KPI placeholders: suggests replacing hardcoded values with configurable thresholds or real metrics

Run the CLI in dry-run mode to review diffs before applying fixes:

npx simplebeacon fix . --fix-dry-run

Documentation: see AUTOFIX.md in the repository for full details and safety notes.
