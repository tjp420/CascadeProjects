Clearance Delivery Guide

After payment, send your gate JSON report. We format it into an executive clearance PDF within 48 hours.

Step 1: Run the gate locally

Generate your gate JSON report from your repository.

npx simplebeacon scan --gate --offline

This creates a simplebeacon-gate-report.json file in your repository root.

Step 2: Locate your gate report

Find the JSON file in your repository:

  • Default location: ./simplebeacon-gate-report.json
  • Or in your configured output directory
  • File size should be under 1 MB for most repositories

Step 3: Send your gate report

Email your JSON report to the address provided in your payment confirmation.

  • Attach the simplebeacon-gate-report.json file
  • Include your order/payment reference number
  • Mention your target delivery date if urgent
  • No source code or zip files needed — JSON only

Security note: The JSON report contains only scan findings, file paths, and issue counts — no source code content, credentials, or secrets.

Step 4: Receive your clearance PDF

Within 48 hours, you'll receive:

  • Executive clearance PDF formatted for client presentation
  • Gate verdict and readiness score
  • Developer remediation recipes for each blocking issue
  • Compliance checklist and sign-off seal

Priority delivery: If you provided a client delivery date, we prioritize your report accordingly.

What's included in the PDF

Your executive clearance PDF includes:

  • Cover page with project metadata and confidentiality notice
  • Executive summary with key findings and risk matrix
  • Detailed remediation matrix with code fixes
  • Compliance checklist (credential patterns, sample paths, AI-fiction KPIs)
  • Production sign-off seal for CTO / Lead Architect

Need help?

If you have questions about the delivery process:

  • Reply to your payment confirmation email
  • Contact us at support
  • Include your order reference number
