# EU AI Act Sprint Implementation Plan

## Goal
Ensure the $2,499 "EU AI Act Sprint" tier delivers exactly what is marketed:
1. Human analyst support for 30 days
2. Regulatory-specific deep dive mapped to EU AI Act articles/annexes
3. Oversight & transparency evaluators (Article 14 + Article 50 checks)
4. Documentation completeness assessment against regulatory standards

---

| Promise | Current Implementation | Gap |

| Article 14 & 50 evaluators | Art. 50 exists but is a boolean WARN/PASS based on AI indicator count only | Art. 50 is shallow; **Art. 14 does not exist** |

## Phase 1: Scanner Engine Gaps (Week 1)

### 1.1 Add Article 14 — Human Oversight Evaluator

**File:** `js/dashboard/scanner-engine.js` — `buildEuAiActControls()`

Add a 5th control after Art. 9:

```javascript
// Art. 14 — Human Oversight (high-risk systems only)
controls.push({
    controlId: 'EU-AIA-ART-14',
    title: 'Human Oversight Measures',
    article: 'Regulation (EU) 2024/1689, Article 14',
    status: aiCount > 0 ? (hasOversightDocs ? 'REVIEW' : 'WARN') : 'PASS',
    severity: aiCount > 0 ? (hasOversightDocs ? 'medium' : 'high') : 'low',
    description: aiCount > 0
        ? 'High-risk AI systems must be designed to enable effective oversight by natural persons. Requires: (a) oversight via UI, (b) ability to override/correct, (c) awareness of automation bias.'
        : 'No AI indicators — human oversight not applicable.',
    evidence: aiCount > 0 ? `${oversightDocCount} oversight doc(s); ${uiFileCount} UI file(s) with human-in-the-loop patterns` : 'None detected',
    action: aiCount > 0
        ? 'Document: (1) how humans monitor system output, (2) override mechanisms, (3) training for operators, (4) how automation bias is mitigated. Create human-oversight.md if missing.'
        : 'No action needed.'
});
```

**Detection heuristics to add to scanner patterns:**
- Search for files containing: `human-in-the-loop`, `operator override`, `approval required`, `review before`, `manual review`, `supervisor`
- Search UI/framework files for: `confirm before`, `require approval`, `admin panel`, `moderation queue`
- Flag any AI-generated content pipeline that lacks a blocking human review step

### 1.2 Deepen Article 50 — Transparency Obligations

Current check: `aiCount > 0 ? 'WARN' : 'PASS'`

Replace with multi-factor evaluator:

```javascript
// Art. 50 — Enhanced Transparency Check
const hasChatbot = sourceFiles.some(f => /chatbot|chat|conversation|assistant|bot/i.test(f.path));
const hasGenerativeMedia = sourceFiles.some(f => /generateImage|generateVideo|synth|deepfake|fake|synthetic/i.test(f.path));
const hasDisclosureUI = sourceFiles.some(f => /this is an ai|generated by ai|ai assistant|not human/i.test(f.content));
const hasWatermarking = sourceFiles.some(f => /watermark|metadata.*ai|content authenticity/i.test(f.content));

const transparencyChecks = [
    { name: 'AI disclosure in UI', pass: hasDisclosureUI || !hasChatbot },
    { name: 'Synthetic media watermarking', pass: hasWatermarking || !hasGenerativeMedia },
    { name: 'Chatbot interaction notice', pass: hasDisclosureUI || !hasChatbot }
];
const transparencyFailCount = transparencyChecks.filter(c => !c.pass).length;
```

Report granular failures instead of blanket WARN.

### 1.3 Add Documentation Completeness Assessment

Create a new function `assessEuAiActDocumentation(files)`:

**Required documents for high-risk AI systems:**
| Document | Pattern to detect | Weight |
|----------|----------------|--------|
| Risk management system (Art. 9) | `risk-assessment`, `risk-management` | Critical |
| Technical documentation (Art. 11) | `technical-documentation`, `system-architecture`, `model-card` | Critical |
| Quality management system (Art. 17) | `quality-management`, `test-plan`, `validation` | Critical |
| Record-keeping logs (Art. 12) | `audit-log`, `activity-log`, `retention` | High |
| Human oversight protocol (Art. 14) | `human-oversight`, `operator-manual`, `override-procedure` | High |
| Transparency notice (Art. 50) | `transparency`, `disclosure`, `user-notice` | Medium |
| Conformity declaration (Art. 48) | `conformity`, `declaration`, `CE-marking` | Medium |
| Post-market monitoring (Art. 72) | `post-market`, `monitoring-plan`, `surveillance` | Medium |

**Scoring:**
- Critical missing = Overall status: INCOMPLETE
- >2 High missing = Overall status: MAJOR GAPS
- >2 Medium missing = Overall status: MINOR GAPS
- Else: COMPLETE

- In `routes/checkout.cjs`, when `tier === 'eu_ai_act_sprint'`:
