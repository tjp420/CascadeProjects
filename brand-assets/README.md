# SimpleBeacon 2.0 Brand Assets Repository

This directory contains brand guidelines and asset requirements for SimpleBeacon 2.0 marketing materials, web presence, and product interfaces.

## Required Assets Checklist

### 1. Logos
- [ ] **logo-primary.svg** - Full logo with text (primary brandmark)
- [ ] **logo-primary.png** - Full logo PNG (300dpi, RGB)
- [ ] **logo-icon.svg** - Icon-only variant (square, no text)
- [ ] **logo-icon.png** - Icon PNG (300dpi, multiple sizes: 16x16, 32x32, 64x64, 128x128, 256x256)
- [ ] **logo-horizontal.svg** - Horizontal layout variant
- [ ] **logo-horizontal.png** - Horizontal PNG variant
- [ ] **logo-dark-bg.svg** - Version optimized for dark backgrounds
- [ ] **logo-light-bg.svg** - Version optimized for light backgrounds
- [ ] **favicon.ico** - Browser favicon (16x16, 32x32)
- [ ] **apple-touch-icon.png** - iOS bookmark icon (180x180)

**File Naming Convention:**
- Format: `logo-[variant]-[size-if-applicable].[format]`
- Variants: primary, icon, horizontal, mark, dark-bg, light-bg
- Sizes: 16, 32, 64, 128, 256 (pixels) or use descriptive names
- Formats: svg, png, ico, webp

## Asset Specifications

### Image Format Standards
- **Primary Format:** PNG with transparency (for web)
- **Web Optimization:** WebP (fallback to PNG)
- **Print:** PDF (vector preferred, high-res CMYK)
- **Social Media:** JPG optimized for respective platform dimensions

### Resolution Standards
- **High-Res (Print):** 300 DPI minimum
- **Web/Screen:** 72 DPI, RGB color space
- **Retina/High-DPI:** 2x resolution (e.g., 2x logos)

### File Size Guidelines
- Logo files: <100KB each
- Screenshots: <500KB (optimized for web)
- Feature images: <300KB
- Hero images: <800KB
- Icons/Favicon: <50KB

## Next Steps for Designer

1. **Review Requirements:** Examine the checklist above and plan asset creation timeline
2. **Setup File Structure:** Create subdirectories as outlined (logos/, screenshots/, etc.)
3. **Create Logo Variations:** Start with primary logo and icon variants (highest priority)
4. **Capture Screenshots:** Record clean, representative UI screenshots at specified resolutions
5. **Design Feature Graphics:** Create compelling 1200x800 feature image illustrations
6. **Prepare Demo Video Assets:** Script and storyboard for video production team
7. **Document Standards:** Maintain consistency using the color palette and naming conventions
8. **Optimize & Export:** Ensure all files meet size and format guidelines before committing
9. **Peer Review:** Have marketing/product team review assets before final deployment
10. **Version Control:** Commit with descriptive messages (e.g., "Add logo primary variants SVG/PNG")
