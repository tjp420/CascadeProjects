## 🏗️ Technical Architecture

### Server Configuration
- **Server Type**: Node.js HTTP Server
- **Port**: 54358
- **Framework**: Pure Node.js (no external dependencies)
- **Data Source**: Inline GGUF analysis data with API endpoints

### API Endpoints
```
GET  /api/gguf/analysis          - Main GGUF analysis data
GET  /api/gguf/issues           - Detected issues data
GET  /api/gguf/recommendations  - AI recommendations
POST /api/gguf/refresh          - Data refresh endpoint
GET  /api/gguf/export/csv       - CSV export
GET  /api/gguf/export/json      - JSON export
POST /api/gguf/search           - Search and filter
GET  /api/gguf/stats            - Statistics data
```

### Frontend Components
- **Dashboard HTML**: Single-page application with Bootstrap 5
- **JavaScript**: Vanilla JS with inline class implementations
- **Styling**: Dark theme with CSS custom properties
- **Charts**: Chart.js for data visualization

## 🛠️ Troubleshooting

### Common Issues

#### Server Won't Start
- **Check Port**: Ensure port 54358 is not in use
- **Node.js Version**: Verify Node.js is properly installed
- **File Permissions**: Ensure read access to all files

#### Dashboard Not Loading
- **Server Status**: Confirm server is running
- **URL**: Check correct port in browser URL
- **Console Errors**: Open browser console for error messages

#### Export Not Working
- **JavaScript Errors**: Check browser console for errors
- **File Permissions**: Ensure download directory is accessible
- **Network Issues**: Verify server connectivity

#### Data Not Displaying
- **API Endpoints**: Test `/api/gguf/analysis` endpoint
- **Data Format**: Verify JSON structure is valid
- **Cache Issues**: Try refreshing the page

### Error Messages
- **"function not defined"**: JavaScript loading issue - refresh page
- **"Failed to load"**: Network or server issue - check server status
- **"Export failed"**: Format or data issue - try different format
