## PRESS FAQ

**Common Press Questions & Answers**

### 1. What problem does SimpleBeacon solve?
**A:** Legacy vulnerability scanning tools are complex to deploy, slow to deliver results, and generate false positives that overwhelm security teams. SimpleBeacon uses AI to analyze applications intelligently, prioritize real risks, and reduce alert fatigue by 80%. Teams can focus on actual security work instead of managing tool overhead.

### 2. How is SimpleBeacon different from existing vulnerability scanners?
**A:** Traditional scanners use rule-based detection; SimpleBeacon uses behavioral AI analysis combined with dependency intelligence and configuration review. This means we catch vulnerabilities rule-based tools miss, eliminate false positives, and provide context-aware remediation guidance. We also launched with enterprise features like RBAC and compliance automation that typically cost extra elsewhere.

### 3. What deployment options are available?
**A:** SimpleBeacon supports Docker Compose (for dev/staging), Kubernetes (for large-scale deployments), cloud-hosted managed service, and on-premises installation. Enterprise customers can deploy entirely within their own infrastructure for maximum security and compliance.

### 4. Is SimpleBeacon compliant with security regulations?
**A:** Yes. SimpleBeacon generates automated reports for SOC 2 Type II, ISO 27001, GDPR, HIPAA, and PCI DSS compliance frameworks. The platform includes audit trail logging, role-based access controls, and data residency options to meet regulatory requirements out-of-box.

### 5. How does SimpleBeacon handle sensitive data?
**A:** SimpleBeacon employs end-to-end encryption for data in transit and at rest, follows OWASP Top 10 security standards, and conducts regular penetration testing. Enterprise deployments can be fully air-gapped and store all data on-premises. We provide SOC 2 Type II certification and publicly available security documentation.

### 6. What is the typical onboarding timeline?
**A:** SimpleBeacon is designed for rapid deployment. Most organizations complete setup and run their first security scan within 15 minutes. Enterprise deployments with custom RBAC and compliance workflows typically take 1-2 weeks.

### 7. What are the pricing and licensing models?
**A:** [INSERT PRICING INFORMATION]. We offer usage-based, subscription, and enterprise perpetual licensing. Free tier available for open-source projects and non-profit organizations.

### 8. Can SimpleBeacon integrate with existing security tools?
**A:** Yes. SimpleBeacon provides webhooks, REST APIs, and pre-built integrations for SIEM platforms (Splunk, Datadog, New Relic), ticketing systems (Jira, Azure DevOps), and orchestration tools (Terraform, Ansible). Custom integrations can be developed using our public API.

### 9. What types of vulnerabilities can SimpleBeacon detect?
**A:** SimpleBeacon identifies OWASP Top 10 vulnerabilities, supply chain risks, configuration misconfigurations, credential exposure, unpatched dependencies, and behavioral anomalies. The AI model is continuously updated as new vulnerability patterns emerge.

### 10. What kind of support does SimpleBeacon provide?
**A:** All tiers include documentation, community forums, and ticketing support. Professional and enterprise tiers include dedicated support engineers, SLA guarantees (99.9% uptime), and custom training for security teams.
