##      🔧 Troubleshooting

###      Common Issues and Solutions

####      Issue: Drag & Drop Not Working
**Solution:** Use Direct Browser Access
- Copy the URL and paste directly into browser address bar
- Avoid using preview systems that block JavaScript

####      Issue: CSP Restrictions
**Solution:** Use CSP-Safe Versions
- All provided solutions are CSP-safe
- No inline event handlers used
- addEventListener implementation

####      Issue: Server Not Responding
**Solution:** Check Flask Server
- Ensure Flask server is running on port 5000
- Check for firewall restrictions
- Verify port availability

####      Issue: File Upload Fails
**Solution:** Check File Permissions
- Ensure files are accessible
- Check file size limits
- Verify supported file types

###      Frequently Asked Questions

**Q: Why use direct browser access?**
A:
    Direct browser access bypasses Content Security Policy restrictions that block JavaScript functionality in preview systems.

**Q: Are my files uploaded to external servers?**
A: No. All analysis happens locally in your browser. Files never leave your computer.

**Q: What file types are supported?**
A: Python (.py),
    JavaScript (.js), HTML (.html), CSS (.css), Markdown (.md), Text (.txt), and JSON (.json).

**Q: Can I analyze multiple files at once?**
A: Yes. Drag and drop multiple files or use the batch analysis features.

**Q: How do I export analysis results?**
A: Use the export buttons to generate JSON, CSV, or
    TXT reports with complete analysis data.
