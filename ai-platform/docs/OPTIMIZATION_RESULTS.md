## 🚀 Ready-to-Use Commands

### Quick Start
```bash
# Install dependencies
pip install scripts/requirements.txt
npm install

# Run health check
npm run optimize:dry-run

# Apply quick fixes
python scripts/dashboard_quick_fix.py dashboard.html

# Full optimization (when ready)
npm run optimize:full
```

### Individual Utilities
```bash
# Database optimization
python scripts/database_optimizer.py database.db

# File compression
python scripts/data_compressor.py large_file.json --method lzma

# Filename sanitization
python scripts/filename_sanitizer.py /path/to/directory

# Security validation
python scripts/file_security_validator.py file.txt

# Health monitoring
python scripts/dashboard_health_check.py dashboard.html
```
