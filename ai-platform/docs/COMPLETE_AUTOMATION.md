## 🚀 How to Use (2 Minutes Total)

### Step 1: Create UE5 Project (1 minute)
1. Open Epic Games Launcher
2. Launch UE5.3+
3. Create Blank Project: "UE5WireframeTool"
4. Save to: `C:\Users\Trevor\CascadeProjects\UE5WireframeTool\`

### Step 2: Run Automation (30 seconds)
1. In UE5: **Tools → Python Scripts → Run Script**
2. Select: **INSTANT_WIREFRAME.py**
3. Click **Run**

### Step 3: Use It (30 seconds)
1. Import any image into `/Game/WireframeTool/Textures/`
2. Select the generator in the level
3. Assign your image to **InputImage** variable
4. Press **Play**
5. **Wireframe appears!**
