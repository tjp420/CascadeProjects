## Troubleshooting

### If Game Doesn't Load
1. Check browser console for errors (F12)
2. Ensure WebGL is enabled in browser
3. Try refreshing the page
4. Clear browser cache

### If Controls Don't Respond
1. Click on the game canvas to focus it
2. Ensure browser window is active
3. Try different keyboard keys

### Performance Issues
1. Close other browser tabs
2. Lower browser zoom level
3. Check graphics driver updates
