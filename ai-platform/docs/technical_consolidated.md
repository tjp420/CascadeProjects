## ⚠️ Error Handling

### **Standard Error Response Format**

All API errors follow this consistent format:

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error message",
    "details": {
      "field": "specific_field",
      "reason": "detailed_explanation"
    }
  }
}
```

### **Common Error Codes**

| Code | HTTP Status | Description |
|------|-------------|-------------|
| `INVALID_REQUEST` | 400 | Request validation failed |
| `UNAUTHORIZED` | 401 | Authentication required |
| `FORBIDDEN` | 403 | Insufficient permissions |
| `NOT_FOUND` | 404 | Resource not found |
| `RATE_LIMITED` | 429 | Too many requests |
| `SERVER_ERROR` | 500 | Internal server error |

### **Error Handling Example**

```javascript
try {
  const data = await apiService.get('/users/12345');
} catch (error) {
  if (error.message.includes('404')) {
    console.log('User not found');
  } else if (error.message.includes('429')) {
    console.log('Rate limit exceeded');
  } else {
    console.log('Server error:', error.message);
  }
}
```

## ⏱️ Rate Limiting

### **Rate Limiting Rules**

- **Default Limit:** 50 requests per minute per user
- **Burst Limit:** 10 requests per second
- **Headers Returned:**
  - `X-RateLimit-Limit`: Total requests allowed
  - `X-RateLimit-Remaining`: Requests remaining
  - `X-RateLimit-Reset`: Unix timestamp when limit resets

### **Rate Limit Exceeded Response**

```json
{
  "success": false,
  "error": {
    "code": "RATE_LIMITED",
    "message": "Rate limit exceeded. Please try again later.",
    "retryAfter": 60
  }
}
```

### **Handling Rate Limits**

```javascript
try {
  const data = await apiService.get('/data');
} catch (error) {
  if (error.message.includes('Rate limit')) {
    const retryAfter = parseInt(error.message.match(/\d+/)[0]);
    setTimeout(() => retryRequest(), retryAfter * 1000);
  }
}
```

### **Error Handling with Retry**

```javascript
async function makeRequestWithRetry(endpoint, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await apiService.get(endpoint);
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      
      // Wait before retry (exponential backoff)
      await new Promise(resolve => setTimeout(resolve, Math.pow(2, i) * 1000));
    }
  }
}
```

# CI_CD_GUIDE.md

# CI/CD Integration Guide

## Overview

This guide documents the CI/CD integration and coverage gates for the Technical Debt Dashboard project. The CI/CD pipeline ensures code quality, test coverage, and security standards are maintained across all commits and pull requests.

## CI/CD Pipeline Architecture

### Pipeline Stages

#### 1. Test and Coverage
- **Purpose**: Run all tests and measure code coverage
- **Python Versions**: 3.9, 3.10, 3.11
- **Test Suites**:
  - Unit tests (routers, services, microservices)
  - Integration tests (critical paths)
  - E2E mock tests
  - Performance tests
- **Coverage Requirements**: Minimum 70% coverage
- **Artifacts**: Coverage reports (XML, HTML, terminal)

#### 2. Lint and Quality
- **Purpose**: Ensure code quality and consistency
- **Tools**:
  - Black (code formatting)
  - Flake8 (linting)
  - MyPy (type checking)
  - Pylint (code analysis)
- **Fail Conditions**: Formatting or linting errors

#### 3. Security Scan
- **Purpose**: Identify security vulnerabilities
- **Tools**:
  - Bandit (security linter)
  - Safety (dependency vulnerability scanner)
- **Artifacts**: Security reports (JSON)

#### 4. Build and Deploy
- **Purpose**: Build and deploy package
- **Trigger**: Push to main branch
- **Steps**:
  - Build Python package
  - Publish to PyPI (when configured)
- **Dependencies**: All previous stages must pass

## Coverage Gates

### Coverage Configuration

Coverage thresholds are defined in `.coveragerc`:

```ini
[report]
fail_under = 70
precision = 2
```

### Coverage Requirements

- **Minimum Coverage**: 70%
- **Measured Files**: All Python files in `web/` directory
- **Excluded Files**:
  - Test files (`*/tests/*`, `*/test_*.py`)
  - Cache directories (`*/__pycache__/*`)
  - Virtual environments (`*/.venv/*`, `*/venv/*`)
  - Static files and templates
  - Database migrations

### Coverage Breakdown by Module

Current coverage targets:
- **API Routers**: 75%
- **API Services**: 80%
- **Microservices**: 70%
- **Integration**: 65%
- **Overall**: 70%

## Pre-commit Hooks

### Installation

```bash
pip install pre-commit
pre-commit install
```

### Available Hooks

1. **Code Quality**:
   - Trailing whitespace removal
   - End-of-file fixer
   - YAML/JSON validation
   - Large file detection

2. **Formatting**:
   - Black code formatter
   - Flake8 linter
   - MyPy type checker

3. **Testing**:
   - Pytest execution
   - Coverage verification (minimum 70%)

4. **Security**:
   - Bandit security scanner
   - Private key detection

### Running Hooks Manually

```bash
# Run all hooks on all files
pre-commit run --all-files

# Run specific hook
pre-commit run black --all-files

# Skip hooks (not recommended)
git commit --no-verify -m "message"
```

## GitHub Actions Workflow

### Workflow Triggers

- **Push**: To `main` or `develop` branches
- **Pull Request**: To `main` or `develop` branches
- **Manual**: Via workflow dispatch

### Workflow Jobs

#### Test and Coverage Job

```yaml
test-and-coverage:
  runs-on: ubuntu-latest
  strategy:
    matrix:
      python-version: ['3.9', '3.10', '3.11']
```

**Steps**:
1. Checkout code
2. Set up Python
3. Cache pip dependencies
4. Install dependencies
5. Run unit tests with coverage
6. Run integration tests with coverage
7. Run E2E mock tests with coverage
8. Run performance tests
9. Check coverage thresholds
10. Upload coverage to Codecov
11. Upload coverage reports
12. Comment coverage on PR

#### Lint and Quality Job

```yaml
lint-and-quality:
  runs-on: ubuntu-latest
```

**Steps**:
1. Checkout code
2. Set up Python
3. Install dependencies
4. Run Black formatter check
5. Run Flake8 linter
6. Run MyPy type checking
7. Run Pylint

#### Security Scan Job

```yaml
security-scan:
  runs-on: ubuntu-latest
```

**Steps**:
1. Checkout code
2. Set up Python


5. Publish to PyPI (when configured)

## Troubleshooting

### Coverage Gate Failures

#### Issue: Coverage below threshold
**Solution**:
1. Identify uncovered files: `coverage report --show-missing`
2. Add tests for uncovered code
3. Remove unnecessary code if not needed
4. Update coverage threshold if justified

#### Issue: Tests failing in CI but passing locally
**Solution**:
1. Check Python version differences
2. Verify all dependencies are in requirements.txt
3. Check for environment-specific code
4. Review CI logs for specific errors

### Pre-commit Hook Failures

#### Issue: Black formatting errors
**Solution**:
```bash
black web/
```

#### Issue: Flake8 linting errors
**Solution**:
```bash
flake8 web/ --max-line-length=127
```
Fix reported issues or add `# noqa` comments for intentional exceptions.

#### Issue: MyPy type errors
**Solution**:
```bash
mypy web/ --ignore-missing-imports
```
Add type hints or update mypy configuration.

### Security Scan Failures

#### Issue: Bandit security issues
**Solution**:
1. Review bandit-report.json
2. Fix identified security issues
3. Add `# nosec` comments for false positives

#### Issue: Safety dependency vulnerabilities
**Solution**:
1. Update vulnerable dependencies
2. Review if vulnerability affects your usage
3. Add to safety ignore list if justified

```python
# services/analysis/async_processor.py
class AsyncAnalysisProcessor:
    def __init__(self):
        self.redis_client = redis.Redis()
        self.analysis_queue = Queue("analysis")
    
    async def process_repository_analysis(self, repo_id: UUID):
        """Process repository analysis asynchronously"""
        # Cache intermediate results
        cache_key = f"analysis:{repo_id}"
        
        # Check if analysis is already in progress
        if await self.redis_client.exists(cache_key):
            return await self.redis_client.get(cache_key)
        
        # Mark analysis as in progress
        await self.redis_client.setex(cache_key, 3600, "IN_PROGRESS")
        
        try:
            # Perform analysis in chunks for large codebases
            repo = await repository_repository.get(repo_id)
            codebase = await self.clone_and_analyze(repo.url)
            
            # Parallel analysis for different aspects
            complexity_task = asyncio.create_task(self.analyze_complexity(codebase))
            security_task = asyncio.create_task(self.analyze_security(codebase))
            compliance_task = asyncio.create_task(self.analyze_compliance(codebase))
            
            # Wait for all analyses to complete
            complexity, security, compliance = await asyncio.gather(
                complexity_task, security_task, compliance_task
            )
            
            # Combine results
            analysis_result = AnalysisResult(
                repo_id=repo_id,
                complexity=complexity,
                security=security,
                compliance=compliance,
                ma_analysis=self.perform_ma_specific_analysis(codebase)
            )
            
            # Cache and return results
            await self.redis_client.setex(cache_key, 86400, analysis_result.json())
            return analysis_result
            
        except Exception as e:
            await self.redis_client.setex(cache_key, 300, f"ERROR: {str(e)}")
            raise
```

```python
# services/risk/financial_impact.py
class FinancialImpactModel:
    def __init__(self):
        self.tech_debt_multiplier = 1.5  # Risk multiplier for technical debt
        self.security_vulnerability_cost = {
            'critical': 100000,  # $100K per critical vulnerability
            'high': 25000,       # $25K per high vulnerability
            'medium': 5000,      # $5K per medium vulnerability
            'low': 1000          # $1K per low vulnerability
        }
        self.integration_cost_per_month = 50000  # $50K per integration month
    
    def calculate_deal_adjustment(self, analysis: AnalysisResult) -> DealAdjustment:
        """Calculate recommended deal price adjustment"""
        adjustments = {}
        
        # Technical debt cost adjustment
        tech_debt_cost = analysis.complexity.technical_debt_cost
        adjustments['technical_debt'] = -tech_debt_cost * self.tech_debt_multiplier
        
        # Security vulnerability adjustment
        for vuln in analysis.security.vulnerabilities:
            cost = self.security_vulnerability_cost.get(vuln.severity, 0)
            adjustments[f'security_{vuln.severity}'] = -cost * vuln.count
        
        # Integration complexity adjustment
        integration_months = analysis.ma_analysis.integration_complexity.integration_effort_months
        adjustments['integration'] = -integration_months * self.integration_cost_per_month
        
        # Team retention adjustment
        key_person_risk = analysis.ma_analysis.team_assessment.retention_risk
        adjustments['team_retention'] = -key_person_risk * 100000  # $100K per key person
        
        total_adjustment = sum(adjustments.values())
        
        return DealAdjustment(
            total_adjustment=total_adjustment,
            breakdown=adjustments,
            confidence_score=self.calculate_confidence_score(analysis),
            risk_factors=self.identify_risk_factors(analysis)
        )
    
    def generate_roi_projection(self, analysis: AnalysisResult, deal_value: Decimal) -> ROIProjection:
        """Generate ROI projections for the acquisition"""
        integration_cost = analysis.ma_analysis.integration_complexity.integration_effort_months * self.integration_cost_per_month
        annual_maintenance = analysis.complexity.technical_debt_cost * 0.2  # 20% of tech debt annually
        
        # Best case: Successful integration, low team turnover
        best_case = self.calculate_best_case_roi(deal_value, integration_cost, annual_maintenance)
        
        # Worst case: Integration challenges, high team turnover
        worst_case = self.calculate_worst_case_roi(deal_value, integration_cost, annual_maintenance, analysis)
        
        # Expected case: Most likely outcome
        expected_case = self.calculate_expected_roi(deal_value, integration_cost, annual_maintenance, analysis)
        
        return ROIProjection(
            best_case=best_case,
            worst_case=worst_case,
            expected=expected_case,
            payback_period=self.calculate_payback_period(expected_case),
            confidence_intervals=self.calculate_confidence_intervals(best_case, worst_case)
        )
```

```python
class DistributedAnalysisProcessor:
    def __init__(self):
        self.task_queue = CeleryQueue('analysis_tasks')
        self.result_store = RedisResultStore()
        self.monitoring = PrometheusMetrics()
    
    async def process_large_codebase(self, repo_id: UUID) -> AnalysisResult:
        """Process large codebases using distributed workers"""
        
        repo = await self.repository_repository.get(repo_id)
        
        # Split analysis into chunks for parallel processing
        analysis_chunks = self.create_analysis_chunks(repo)
        
        # Distribute chunks to worker nodes
        tasks = []
        for chunk in analysis_chunks:
            task = self.task_queue.delay('analyze_chunk', chunk.dict())
            tasks.append(task)
        
        # Monitor progress and aggregate results
        results = []
        for task in tasks:
            try:
                result = await task.get(timeout=3600)  # 1 hour timeout
                results.append(result)
                
                # Update progress
                progress = len(results) / len(tasks) * 100
                await self.update_analysis_progress(repo_id, progress)
                
            except Exception as e:
                await self.handle_analysis_error(repo_id, str(e))
                raise
        
        # Aggregate chunk results
        aggregated_result = self.aggregate_results(results)
        
        # Store final result
        await self.result_store.set(f"analysis:{repo_id}", aggregated_result)
        
        # Update metrics
        self.monitoring.increment('analysis_completed')
        self.monitoring.histogram('analysis_duration', time.time() - start_time)
        
        return aggregated_result
    
    def create_analysis_chunks(self, repo: Repository) -> List[AnalysisChunk]:
        """Split repository into manageable chunks for parallel processing"""
        
        # Get repository structure
        repo_structure = self.get_repository_structure(repo.url)
        
        # Create chunks based on file count and size
        chunks = []
        current_chunk = AnalysisChunk(repo_id=repo.id)
        
        for file_path, file_info in repo_structure.items():
            if current_chunk.size_mb > 100 or current_chunk.file_count > 1000:
                chunks.append(current_chunk)
                current_chunk = AnalysisChunk(repo_id=repo.id)
            
            current_chunk.add_file(file_path, file_info)
        
        if current_chunk.file_count > 0:
            chunks.append(current_chunk)
        
        return chunks
```

```python
# services/cache/analysis_cache.py
class AnalysisCache:
    def __init__(self):
        self.redis_client = redis.Redis()
        self.local_cache = LRUCache(maxsize=1000)
        self.cache_stats = CacheStats()
    
    async def get_cached_analysis(self, repo_id: UUID, analysis_type: str) -> Optional[AnalysisResult]:
        """Get cached analysis result with multi-level caching"""
        
        cache_key = f"analysis:{repo_id}:{analysis_type}"
        
        # Try local cache first (fastest)
        result = self.local_cache.get(cache_key)
        if result:
            self.cache_stats.increment('local_cache_hit')
            return result
        
        # Try Redis cache
        cached_data = await self.redis_client.get(cache_key)
        if cached_data:
            result = AnalysisResult.parse_raw(cached_data)
            self.local_cache.set(cache_key, result)
            self.cache_stats.increment('redis_cache_hit')
            return result
        
        self.cache_stats.increment('cache_miss')
        return None
    
    async def cache_analysis_result(self, repo_id: UUID, analysis_type: str, result: AnalysisResult, ttl: int = 86400):
        """Cache analysis result with intelligent TTL"""
        
        cache_key = f"analysis:{repo_id}:{analysis_type}"
        
        # Cache in local memory (fast access)
        self.local_cache.set(cache_key, result)
        
        # Cache in Redis (shared across instances)
        await self.redis_client.setex(cache_key, ttl, result.json())
        
        # Cache related metadata
        await self.cache_analysis_metadata(repo_id, analysis_type, result)
    
    async def invalidate_cache(self, repo_id: UUID):
        """Invalidate all cached results for a repository"""
        
        # Find all cache keys for this repository
        pattern = f"analysis:{repo_id}:*"
        keys = await self.redis_client.keys(pattern)
        
        # Delete from Redis
        if keys:
            await self.redis_client.delete(*keys)
        
        # Invalidate from local cache
        keys_to_remove = [key for key in self.local_cache.keys() if str(repo_id) in key]
        for key in keys_to_remove:
            self.local_cache.remove(key)
```
