What Simplebeacon catches

Production Leaks

Detects mock/sample JSON references in server code and production paths that dependency scanners miss.

Credential Patterns

Flags AWS keys, API tokens, JWTs, and private key blocks in JS/TS and JSON files.

JSON Schema Drift

Validates sample files against registered page specs so front-end data stays consistent.

EU AI Act Readiness

Scans for AI system indicators, transparency gaps, and documentation requirements before the August 2026 deadline.

Fiction KPI Detection

Catches inflated metrics and hardcoded claims in sample JSON that can mislead stakeholders.

Sub-Second Gates

Runs in under a second for typical repos. No heavy infrastructure required.

Install in 30 seconds

$ npx simplebeacon init --profile standard
$ npx simplebeacon scan --gate

Or add to your GitHub Actions workflow:

- run: npx simplebeacon scan --gate
