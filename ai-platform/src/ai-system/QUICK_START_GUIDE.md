## 🔧 **Troubleshooting**

### **Common Issues:**
1. **API Key Not Working:**
   - **Solution:** Run `python setup_api_key.py` and verify your key
   - **Check:** API key format and provider

2. **AI Service Not Available:**
   - **Solution:** Check internet connection
   - **Verify:** API key is valid and has credits

3. **Blob File Errors:**
   - **Solution:** System handles gracefully
   - **Note:** Some blob files may have encoding issues

4. **Python Not Found:**
   - **Solution:** Install Python 3.7+
   - **Check:** Python is in PATH
