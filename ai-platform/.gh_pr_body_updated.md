- **Title:** Standardize AI stub auto-fix and segregate synthetic TODOs

- **Summary:**
  Standardizes how the scanner replaces AI-generated stub implementations by inserting a deterministic, easily-identifiable marker and a fail-fast fallback. Synthetic (auto-generated) TODO markers are tracked separately so they do not inflate user-facing TODO/fix counts. Also updates one test fixture to avoid scanner false positives.

- **Why:**
  Prevents loose AI-generated replacement templates from polluting the project TODO/roadmap metrics, makes auto-fixes deterministic and testable, and eliminates a class of false positives in CI scans.

**What changed**

- Key behavior:
  - Standardized AI-stub replacement in coming-soon/js/dashboard/scanner-engine.js:
    - Inserts // TODO: [Auto-Generated Issue] + // AUTO_FIX: ai_residue and a fail-fast hrow as the deterministic placeholder.
    - Suggestion diffs updated to use the standardized marker.
  - Segregated synthetic TODO aggregation:
    - Added syntheticTodoFiles and syntheticTodoMarkerCounts so auto-generated markers are reported separately in roadmap output.
  - Reporting:
    -

oadmap report now includes syntheticTodoCount, syntheticTodoMarkers, and syntheticTodoFiles.

- Test fixtures:
  - coming-soon/test/scan-utils.test.cjs ΓÇö replaced test TODO strings with MOCK_TODO to avoid scanner false positives.
- Files changed (high-level):
  - coming-soon/js/dashboard/scanner-engine.js
  - coming-soon/test/scan-utils.test.cjs
  - plus test artifacts staged in the commit that were created during the work.
