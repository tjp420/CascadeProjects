## Scanner False Positive: SB-WEBHOOK-001
**File:** `ai-platform/pipeline/main.py`  
**Status:** Verified safe — `stripe.Webhook.construct_event(payload, sig_header, STRIPE_WEBHOOK_SECRET)` is present at line 228.  
**Root cause:** Scanner's Python AST engine walked `0` `.py` files; regex rule flagged docstring "Stripe webhooks" without detecting the actual signature verification.  
**Remediation:** Enabled `python-ast-patterns` in `.simplebeacon/config.json` (was `false`, now `true`). On next scan, the Python AST engine will walk `.py` files and detect `construct_event` calls, clearing this false positive.
