# Security Policy

## Supported Versions

Only the latest published version on npm receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities to **security@simplebeacon.local**.

Include:
- Affected version(s)
- Steps to reproduce
- Expected vs actual behavior
- Impact assessment (if known)

We aim to acknowledge reports within 48 hours and provide a fix timeline within 5 business days.
